# JavaScript 생성자 함수의 `return` 동작

<img width="500" height="500" alt="Image" src="https://github.com/user-attachments/assets/4f9647b4-fd61-4fc6-9d76-e3666ba3327b" />

## 문제 코드

```javascript
function Demo(name) {
  this.name = name;
  return {};
}

const obj = new Demo("Javascript");

console.log(obj.name);
```

## 정답

```text
B. undefined
```

---

# 1. `new Demo("Javascript")` 실행 과정

생성자 함수를 `new`와 함께 호출하면 내부적으로 다음 과정이 진행됩니다.

## ① 새로운 객체 생성

JavaScript 엔진이 새로운 빈 객체를 생성합니다.

```javascript
{}
```

개념적으로 다음과 같습니다.

```javascript
const temporaryObject = {};
```

---

## ② 생성된 객체가 `this`에 연결됨

생성자 함수 내부의 `this`는 새롭게 생성된 객체를 가리킵니다.

```javascript
function Demo(name) {
  this.name = name;
}
```

다음 코드가 실행되면

```javascript
this.name = name;
```

생성된 객체는 다음 상태가 됩니다.

```javascript
{
  name: "Javascript"
}
```

---

## ③ `return {}` 실행

하지만 마지막에 다음 코드가 있습니다.

```javascript
return {};
```

생성자 함수에서 **객체(Object)를 명시적으로 반환하면**, JavaScript는 처음 생성했던 `this` 객체를 버리고 **명시적으로 반환한 객체를 최종 결과**로 사용합니다.

즉,

```javascript
const obj = {};
```

와 동일한 결과가 됩니다.

따라서 `this.name`을 저장했던 객체는 버려집니다.

---

# 2. `obj.name`의 결과

최종적으로 `obj`는

```javascript
{}
```

입니다.

빈 객체에는 `name` 프로퍼티가 없으므로

```javascript
console.log(obj.name);
```

의 결과는

```text
undefined
```

입니다.

---

# 생성자 함수의 반환 규칙

| 반환값 | 최종 반환 결과 |
|--------|----------------|
| `return` 없음 | `this` 객체 반환 |
| 객체(Object) | 반환한 객체 |
| 배열(Array) | 반환한 배열 |
| 함수(Function) | 반환한 함수 |
| 문자열(String) | 무시하고 `this` 반환 |
| 숫자(Number) | 무시하고 `this` 반환 |
| 불리언(Boolean) | 무시하고 `this` 반환 |
| `null` | 무시하고 `this` 반환 |
| `undefined` | 무시하고 `this` 반환 |

> **객체만 예외적으로 반환값이 적용되고, 원시값은 모두 무시됩니다.**

---

# 객체를 반환하지 않는 경우

```javascript
function Demo(name) {
  this.name = name;
}

const obj = new Demo("Javascript");

console.log(obj.name);
```

### 결과

```text
Javascript
```

명시적인 객체 반환이 없으므로 `new`가 생성한 `this` 객체가 반환됩니다.

---

# 원시값을 반환하는 경우

```javascript
function Demo(name) {
  this.name = name;
  return 100;
}

const obj = new Demo("Javascript");

console.log(obj.name);
```

### 결과

```text
Javascript
```

숫자, 문자열, 불리언 같은 **원시값은 무시**됩니다.

실제로 반환되는 객체는

```javascript
{
  name: "Javascript"
}
```

입니다.

---

# 객체를 반환하는 경우

```javascript
function Demo(name) {
  this.name = name;

  return {
    language: name
  };
}

const obj = new Demo("Javascript");

console.log(obj.name);
console.log(obj.language);
```

### 결과

```text
undefined
Javascript
```

최종적으로 반환되는 객체는

```javascript
{
  language: "Javascript"
}
```

이므로 `name`은 존재하지 않습니다.

---

# 내부적으로 동작하는 모습

원본 코드는 개념적으로 다음과 같습니다.

```javascript
function createDemo(name) {
  const temporaryThis = {};

  temporaryThis.name = name;

  const returnedObject = {};

  return returnedObject;
}

const obj = createDemo("Javascript");

console.log(obj.name);
```

`temporaryThis`에는 `name`이 저장되지만,

최종적으로는 `returnedObject`가 반환되므로 `name`은 사라집니다.

---

# 면접에서 꼭 기억할 핵심

- `new`는 새로운 객체를 생성하고 `this`에 연결한다.
- 생성자 함수에서 **객체(Object)를 반환하면 `this`는 무시된다.**
- 생성자 함수에서 **원시값(Number, String, Boolean 등)을 반환하면 무시되고 `this`가 반환된다.**
- 따라서 문제의 `obj`는 빈 객체 `{}` 이므로 `obj.name`은 `undefined`이다.
