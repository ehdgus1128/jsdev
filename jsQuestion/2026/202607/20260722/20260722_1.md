# JavaScript `var`와 함수 선언문의 이름 충돌

## 문제 코드

```javascript
var name = function name() {
  console.log('React js');
};

function name() {
  console.log('Javascript');
}

name();
```

---

# 정답

**출력 결과**

```text
React js
```

> 따라서 정답은 **A. ReactJs**입니다.
>
> (실제 출력 문자열은 코드에 작성된 그대로 `React js`입니다.)

---

# 왜 이렇게 출력될까?

이 문제는 다음 두 가지 개념을 알고 있는지 묻는 문제입니다.

1. **함수 선언문(Function Declaration)의 호이스팅**
2. **`var`의 호이스팅**

---

# 1. 함수 선언문은 먼저 생성된다.

다음 함수는 코드 실행 전에 메모리에 먼저 등록됩니다.

```javascript
function name() {
  console.log('Javascript');
}
```

즉, 실행 전에 이미 아래와 같은 상태가 됩니다.

```javascript
name = function () {
  console.log('Javascript');
};
```

---

# 2. `var`는 선언만 호이스팅된다.

다음 코드는

```javascript
var name = function name() {
  console.log('React js');
};
```

자바스크립트 엔진은 내부적으로 다음처럼 이해합니다.

```javascript
var name;

name = function name() {
  console.log('React js');
};
```

여기서 중요한 점은

- `var name`만 위로 올라간다.
- 함수를 대입하는 부분은 원래 위치에서 실행된다.

---

# 실제 호이스팅 후 모습

자바스크립트 엔진이 이해하는 형태를 그려보면

```javascript
// 함수 선언문이 먼저 등록
function name() {
  console.log('Javascript');
}

// var 선언은 호이스팅
var name;

// 실행 단계
name = function name() {
  console.log('React js');
};

name();
```

---

# 실행 순서

## ① 선언 단계

먼저 함수 선언문이 등록됩니다.

```javascript
name
```

↓

```javascript
function () {
  console.log("Javascript");
}
```

그 다음

```javascript
var name;
```

도 처리됩니다.

하지만 이미 같은 이름의 함수가 존재하기 때문에

```javascript
undefined
```

로 덮어쓰지 않습니다.

현재 상태

```text
name
 ↓
Javascript 출력 함수
```

---

## ② 실행 단계

다음 코드가 실행됩니다.

```javascript
var name = function name() {
  console.log('React js');
};
```

이미 선언은 끝났기 때문에

실제로 실행되는 것은

```javascript
name = function name() {
  console.log('React js');
};
```

뿐입니다.

즉,

기존 함수를

```text
Javascript
```

↓

새 함수

```text
React js
```

로 교체합니다.

현재 상태

```text
name
 ↓
React js 출력 함수
```

---

## ③ 마지막

```javascript
name();
```

현재 `name`은

```javascript
function () {
    console.log("React js");
}
```

를 가리키고 있으므로

출력은

```text
React js
```

입니다.

## 처음

```
name

Javascript 함수
```

## 함수 표현식 실행 후

```
name
 ↓
React js 함수
```

---

## 호출

```
name()

↓

React js 출력
```

# 함수 표현식의 이름은 왜 또 `name`인가?

코드를 보면

```javascript
var name = function name() {
    console.log("React js");
};
```

`name`이 두 번 등장합니다.

첫 번째

```javascript
var name
```

은 **변수 이름**입니다.

두 번째

```javascript
function name()
```

은 **함수 자신의 이름**입니다.

이 이름은

- 재귀 호출
- 디버깅

등을 위해 존재합니다.

예를 들어

```javascript
var factorial = function calculate(n) {
    if (n <= 1) return 1;
    return n * calculate(n - 1);
};

console.log(factorial(5));
```

여기서는

- 변수 이름 → `factorial`
- 함수 이름 → `calculate`

입니다.

---

# 많이 하는 착각

다음 함수가 아래에 있으니까

```javascript
function name() {
    console.log("Javascript");
}
```

나중에 실행되어

```
Javascript
```

가 출력된다고 생각하기 쉽습니다.

하지만

함수 선언문은 **실행되는 코드가 아니라**

코드가 시작되기 전에 이미 등록됩니다.

그리고 실행 단계에서는

```javascript
name = function name() {
    console.log("React js");
}
```

가 실행되어

기존 함수를 덮어씁니다.

그래서 최종적으로

```
React js
```

가 출력됩니다.

---

# 만약 `let` 또는 `const`였다면?

```javascript
let name = function () {
    console.log("React js");
};

function name() {
    console.log("Javascript");
}
```

실행 결과

```text
SyntaxError:
Identifier 'name' has already been declared
```

`let`과 `const`는 같은 스코프에서 동일한 이름의 재선언을 허용하지 않기 때문입니다.

---

# 핵심 정리

1. 함수 선언문은 **전체가 호이스팅**된다.
2. `var`는 **선언만 호이스팅**된다.
3. `var`의 함수 표현식은 실행 시점에 대입된다.
4. 실행 단계에서 기존 함수를 새로운 함수가 덮어쓴다.
5. 따라서 `name()`은 **React js**를 출력한다.

---

# 최종 실행 흐름

```text
함수 선언문 호이스팅
        │
        ▼
name → Javascript 함수
        │
        ▼
var 선언 호이스팅
(변화 없음)
        │
        ▼
함수 표현식 대입
        │
        ▼
name → React js 함수
        │
        ▼
name()
        │
        ▼
React js 출력
```
