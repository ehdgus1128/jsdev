# JavaScript 함수 선언문과 `var` 이름 충돌

<img width="500" height="500" alt="Image" src="https://github.com/user-attachments/assets/58c1ebe3-0c31-4531-bf68-2114644f2d5a" />

## 문제

```javascript
var name = 'jascript';

function name() {
  console.log('Javascript');
}

name();
```

### 예상 출력

- A. Javascript
- B. undefined
- C. Error

---

# 정답

✅ **C. Error**

실행하면 다음과 같은 오류가 발생합니다.

```text
TypeError: name is not a function
```

---

# 왜 오류가 발생할까?

이 코드에서는 **변수와 함수가 같은 이름(`name`)** 을 사용하고 있습니다.

```javascript
var name = 'jascript';

function name() {
  console.log('Javascript');
}
```

JavaScript는 실행 전에 **호이스팅(Hoisting)** 을 수행합니다.

---

# 1. 호이스팅(Hoisting)

JavaScript는 코드를 실행하기 전에 선언을 먼저 처리합니다.

이 과정에서

- 함수 선언문은 **함수 전체가 호이스팅**
- `var`는 **선언만 호이스팅**

됩니다.

즉, 내부적으로는 다음과 비슷하게 동작합니다.

```javascript
function name() {
  console.log('Javascript');
}

var name;
```

여기까지는 `name`이 함수입니다.

---

# 2. 코드 실행

이제 원래 코드가 위에서부터 실행됩니다.

```javascript
name = 'jascript';
```

여기서 함수였던 `name`이 문자열로 덮어씌워집니다.

현재 상태

```javascript
console.log(name);
// "jascript"
```

즉,

```javascript
name
```

은 더 이상 함수가 아닙니다.

---

# 3. 함수 호출

마지막 코드

```javascript
name();
```

현재 `name`의 실제 값은

```javascript
'jascript'
```

입니다.

즉,

```javascript
'jascript'();
```

를 실행하는 것과 같습니다.

문자열은 함수가 아니므로

```text
TypeError: name is not a function
```

오류가 발생합니다.

---

```javascript

```

↓

```javascript
name();
```

↓

```text

```

# 메모리 관점에서 이해하기

## ① 호이스팅 직후

| 식별자 | 값 |
|--------|----|
| name | function |

---

## ② 문자열 대입 후

| 식별자 | 값 |
|--------|----|
| name | "jascript" |

함수가 사라진 것이 아니라

**같은 변수에 문자열이 덮어쓴 것**입니다.

---

## ③ 호출

```javascript
name();
```

실제로는

```javascript
'jascript'();
```

이 되어 오류가 발생합니다.

# undefined가 아닌 이유

많은 사람들이

```
var라서 undefined 아닌가?
```

라고 생각합니다.

하지만 아닙니다.

예를 들어

```javascript
var name;

console.log(name);
```

이라면

```text
undefined
```

가 맞습니다.

그러나 문제에서는

```javascript
var name = 'jascript';
```

로 값을 대입했습니다.

즉,

```javascript
console.log(name);
```

의 결과는

```text
jascript
```

입니다.

따라서

```javascript
name();
```

은

```javascript
'jascript'();
```

가 되어 오류가 발생합니다.

---

# 함수 선언문과 var의 우선순위

동일한 이름일 경우

```javascript
function name() {}
var name;
```

에서는

초기에는 함수가 살아 있습니다.

하지만

```javascript
name = 'jascript';
```

가 실행되는 순간

문자열이 함수를 덮어씁니다.

즉

```
호이스팅 우선순위
함수 선언 > var 선언

실행 우선순위
나중에 실행된 대입문이 최종 값을 결정
```

---

# 함수 선언과 변수 선언 비교

## 함수 선언문

```javascript
function hello() {}
```

호이스팅 시

```javascript
hello
```

에는 함수 객체가 들어갑니다.

---

## var

```javascript
var hello = 'abc';
```

호이스팅 시

```javascript
var hello;
```

만 수행됩니다.

값은 나중에 대입됩니다.

---

# 실제 실행 흐름

JavaScript 엔진이 이해하는 형태는 다음과 비슷합니다.

```javascript
function name() {
    console.log('Javascript');
}

var name;

name = 'jascript';

name();
```

---

# 정상적인 코드

변수와 함수 이름을 다르게 사용하면 됩니다.

```javascript
var languageName = 'javascript';

function printLanguage() {
    console.log(languageName);
}

printLanguage();
```

출력

```text
javascript
```

또는

```javascript
function printJavascript() {
    console.log('Javascript');
}

printJavascript();
```

출력

```text
Javascript
```

# 면접에서 자주 나오는 질문

## Q1. 왜 함수가 먼저 살아있나요?

함수 선언문은 **함수 객체 자체까지 호이스팅**되기 때문입니다.

---

## Q2. 그럼 왜 함수가 없어졌나요?

없어진 것이 아니라

```javascript
name = 'jascript';
```

가 실행되면서

같은 식별자에 문자열이 저장되어 함수를 덮어쓴 것입니다.

---

## Q3. 왜 undefined가 아니죠?

이미 문자열이 저장되어 있기 때문입니다.

현재 값은

```javascript
typeof name
```

결과

```text
string
```

입니다.

---

## Q4. 왜 TypeError인가요?

호출 가능한 대상(CallAble)이 아니기 때문입니다.

JavaScript에서 함수 호출은

```javascript
식별자()
```

형태입니다.

현재

```javascript
name
```

은 문자열이므로

```javascript
'jascript'();
```

가 되고,

문자열은 호출할 수 없기 때문에

```text
TypeError: name is not a function
```

이 발생합니다.

---

# 핵심 요약

- JavaScript는 실행 전에 **호이스팅(Hoisting)** 을 수행한다.
- 함수 선언문은 **함수 전체가 호이스팅**된다.
- `var`는 **선언만 호이스팅**되고 값은 나중에 대입된다.
- `name = 'jascript'`가 실행되면서 함수가 문자열로 덮어써진다.
- 마지막 `name()`은 실제로 `'jascript'()`를 호출하는 것과 같다.
- 문자열은 함수가 아니므로 `TypeError: name is not a function`이 발생한다.
- 변수와 함수는 동일한 이름을 사용하지 않는 것이 좋다.
