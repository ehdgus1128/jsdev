# JavaScript `this`, `call()`, 일반 함수와 화살표 함수 문제
<img width="500" height="500" alt="Image" src="https://github.com/user-attachments/assets/a38644b4-6d69-4326-9d75-b85552a47e76" />
## 문제

```javascript
var name = 'javascript';

function outer() {
  function fn1() {
    console.log(this.name);
  }

  fn1();

  return () => console.log(this.name);
}

const fn2 = outer.call({ name: 'Nodejs' });
fn2();
```

### 보기

```text
A. javascript, Nodejs
B. Nodejs, javascript
C. javascript, javascript
D. Nodejs, Nodejs
```

## 정답

```text
A. javascript, Nodejs
```

단, 이 결과는 **브라우저의 일반 스크립트 환경이며 strict mode가 아닌 경우**를 기준으로 합니다.

```text

10. fn2() 실행
11. 화살표 함수는 outer의 this를 사용
12. Nodejs 출력
```

## 1. 전역 변수 `name`

```javascript
var name = 'javascript';
```

브라우저의 일반 스크립트에서 `var`로 선언한 전역 변수는 전역 객체인 `window`의 프로퍼티가 됩니다.

개념적으로는 다음과 비슷합니다.

```javascript
window.name = 'javascript';
```

따라서 다음 값이 존재합니다.

```javascript
window.name; // 'javascript'
```

---

## 2. `outer.call()` 실행

```javascript
const fn2 = outer.call({ name: 'Nodejs' });
```

`call()`은 함수를 실행하면서 함수 내부의 `this`를 직접 지정합니다.

따라서 `outer` 내부에서는 다음과 같습니다.

```javascript
this === { name: 'Nodejs' };
```

개념적으로 보면:

```javascript
function outer() {
  // 여기서 this는 { name: 'Nodejs' }
}
```

---

## 3. `fn1()` 실행 결과

```javascript
function fn1() {
  console.log(this.name);
}

fn1();
```

`fn1`은 일반 함수입니다.

일반 함수의 `this`는 함수가 어디에서 만들어졌는지가 아니라, **어떻게 호출되었는지**에 따라 결정됩니다.

현재 호출 방식은 다음과 같습니다.

```javascript
fn1();
```

객체 없이 단독으로 호출했습니다.

브라우저의 비엄격 모드에서는 일반 함수를 단독 호출하면 `this`가 전역 객체인 `window`를 가리킵니다.

```javascript
this === window;
```

따라서 다음 코드가 실행되는 것과 같습니다.

```javascript
console.log(window.name);
```

출력:

```text
javascript
```

### 중요한 점

`fn1`이 `outer` 안에서 선언되었다고 해서 `outer`의 `this`를 자동으로 이어받는 것은 아닙니다.

```javascript
function outer() {
  function fn1() {
    console.log(this.name);
  }

  fn1();
}
```

`fn1`은 일반 함수이므로 호출 방식에 따라 자신의 `this`가 결정됩니다.

---

## 4. `outer`가 화살표 함수를 반환

```javascript
return () => console.log(this.name);
```

`outer`는 화살표 함수를 반환합니다.

화살표 함수는 자신만의 `this`를 만들지 않습니다.

대신 자신이 생성된 바깥 함수의 `this`를 그대로 사용합니다.

이 화살표 함수가 생성될 당시 `outer`의 `this`는 다음 객체입니다.

```javascript
{ name: 'Nodejs' }
```

따라서 반환된 화살표 함수 내부의 `this`도 계속 이 객체를 참조합니다.

---

## 5. 반환된 함수가 `fn2`에 저장

```javascript
const fn2 = outer.call({ name: 'Nodejs' });
```

여기서 `fn2`에 저장되는 것은 `outer` 함수 자체가 아닙니다.

`outer`가 반환한 다음 화살표 함수만 저장됩니다.

```javascript
() => console.log(this.name)
```

개념적으로 보면 다음과 비슷합니다.

```javascript
const savedThis = { name: 'Nodejs' };

const fn2 = () => {
  console.log(savedThis.name);
};
```

실제로 `savedThis`라는 변수가 만들어지는 것은 아니지만, 이해를 위해 단순화한 표현입니다.

---

## 6. `fn2()` 실행 결과

```javascript
fn2();
```

`fn2()`를 실행하면 저장되어 있던 화살표 함수의 본문만 실행됩니다.

```javascript
console.log(this.name);
```

화살표 함수는 자신만의 `this`를 만들지 않으므로, 생성 당시 `outer`의 `this`를 그대로 사용합니다.

```javascript
this.name === 'Nodejs';
```

출력:

```text
Nodejs
```

---

## 왜 `fn2()`를 실행할 때 `fn1()`은 다시 실행되지 않을까?

다음 코드에서:

```javascript
const fn2 = outer.call({ name: 'Nodejs' });
```

`outer`는 한 번 실행됩니다.

그 과정에서 `fn1()`도 이미 한 번 실행됩니다.

```javascript
function outer() {
  function fn1() {
    console.log(this.name);
  }

  fn1(); // outer가 실행될 때 실행됨

  return () => console.log(this.name);
}
```

그 후 `outer`가 반환한 화살표 함수만 `fn2`에 저장됩니다.

```javascript
fn2();
```

`fn2()`는 `outer` 전체를 다시 실행하는 것이 아니라, 반환된 화살표 함수만 실행합니다.

따라서 `fn1()`은 다시 실행되지 않습니다.

## 일반 함수와 화살표 함수의 차이

### 일반 함수

```javascript
function fn1() {
  console.log(this.name);
}
```

일반 함수의 `this`는 호출 방식에 따라 결정됩니다.

```javascript
fn1();                  // 전역 객체 또는 undefined
obj.fn1();              // obj
fn1.call(otherObject);  // otherObject
```

### 화살표 함수

```javascript
() => console.log(this.name)
```

화살표 함수는 자신만의 `this`가 없습니다.

자신이 만들어진 외부 스코프의 `this`를 사용합니다.

```javascript
function outer() {
  return () => console.log(this.name);
}
```

이 화살표 함수는 `outer`의 `this`를 사용합니다.

## 실행 환경에 따른 차이

이 문제는 실행 환경에 따라 첫 번째 출력이 달라질 수 있습니다.

### 브라우저 일반 스크립트, 비엄격 모드

```text
javascript
Nodejs
```

### strict mode

```javascript
'use strict';
```

`fn1()`을 단독 호출하면 `this`가 `undefined`입니다.

따라서 다음 코드에서 오류가 발생합니다.

```javascript
console.log(this.name);
```

오류 예시:

```text
TypeError: Cannot read properties of undefined
```

### ES Module

ES Module은 기본적으로 strict mode로 동작합니다.

따라서 `fn1()` 실행 중 같은 종류의 오류가 발생할 수 있습니다.

### Node.js CommonJS

Node.js CommonJS에서는 전역의 `var name`이 브라우저의 `window.name`처럼 동작하지 않습니다.

따라서 첫 번째 값은 일반적으로 `undefined`가 될 수 있고, 두 번째 값은 `Nodejs`입니다.
