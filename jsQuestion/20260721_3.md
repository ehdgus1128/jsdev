
# JavaScript `var`와 `setTimeout` 출력 문제

<img width="300" height="300" alt="Image" src="https://github.com/user-attachments/assets/27d963c7-636a-4bec-90d9-e5ffb6336bb0" />

## 문제

```javascript
for (var i = 0; i < 4; i++) {
  setTimeout(() => {
    console.log(i);
  }, 10);
}
```

## 정답

```text
4
4
4
4
```

---

## 왜 `0, 1, 2, 3`이 아니라 모두 `4`가 출력될까?

핵심 이유는 두 가지입니다.

1. `var`로 선언한 `i`는 반복문 전체에서 하나의 변수를 공유합니다.
2. `setTimeout` 콜백은 현재 실행 중인 동기 코드가 모두 끝난 뒤 실행됩니다.

---

## 실행 순서

반복문이 실행되면서 `setTimeout` 콜백 4개가 등록됩니다.

```text
i = 0 → 콜백 등록
i = 1 → 콜백 등록
i = 2 → 콜백 등록
i = 3 → 콜백 등록
```

하지만 이 시점에는 `console.log(i)`가 바로 실행되지 않습니다.

반복문이 모두 끝난 뒤에는 `i++`가 한 번 더 실행되어 `i`가 `4`가 됩니다.

```text
i = 4
i < 4 → false
반복문 종료
```

그다음 등록되어 있던 콜백 4개가 실행됩니다.

모든 콜백은 같은 `i` 변수를 참조하고 있고, 그때의 `i` 값은 `4`이므로 다음처럼 출력됩니다.

```text
4
4
4
4
```

---

## `setTimeout`은 정확히 10ms 뒤에 실행되는가?

```javascript
setTimeout(callback, 10);
```

이 코드는 콜백을 정확히 10ms 뒤에 즉시 실행한다는 뜻이 아닙니다.

10ms가 지난 뒤 콜백을 실행 가능한 작업으로 등록하고, 현재 실행 중인 동기 코드와 콜 스택이 모두 끝난 뒤 실행합니다.

즉, 이 코드에서는 먼저 `for`문 전체가 끝나고 나서 콜백이 실행됩니다.

---

## `var`는 하나의 변수를 공유한다

```javascript
for (var i = 0; i < 4; i++) {
  setTimeout(() => {
    console.log(i);
  }, 10);
}
```

`var i`는 각 반복마다 새로 만들어지는 것이 아닙니다.

모든 콜백이 하나의 `i`를 함께 참조합니다.

개념적으로는 다음과 비슷합니다.

```javascript
var i;

i = 0;
setTimeout(() => console.log(i), 10);

i = 1;
setTimeout(() => console.log(i), 10);

i = 2;
setTimeout(() => console.log(i), 10);

i = 3;
setTimeout(() => console.log(i), 10);

i = 4;
```

콜백이 실제로 실행될 때는 이미 `i`가 `4`입니다.

---

## `let`을 사용하면

```javascript
for (let i = 0; i < 4; i++) {
  setTimeout(() => {
    console.log(i);
  }, 10);
}
```

출력은 다음과 같습니다.

```text
0
1
2
3
```

`let`은 블록 스코프를 가지며, `for`문의 각 반복마다 새로운 `i` 바인딩이 생성됩니다.

개념적으로 보면 다음과 같습니다.

```javascript
{
  let i = 0;
  setTimeout(() => console.log(i), 10);
}

{
  let i = 1;
  setTimeout(() => console.log(i), 10);
}

{
  let i = 2;
  setTimeout(() => console.log(i), 10);
}

{
  let i = 3;
  setTimeout(() => console.log(i), 10);
}
```

각 콜백이 서로 다른 `i`를 참조하므로 `0, 1, 2, 3`이 출력됩니다.

---

## `var`를 유지하면서 해결하는 방법

### IIFE 사용

```javascript
for (var i = 0; i < 4; i++) {
  ((currentI) => {
    setTimeout(() => {
      console.log(currentI);
    }, 10);
  })(i);
}
```

출력:

```text
0
1
2
3
```

반복 시점의 `i` 값을 `currentI` 매개변수에 전달하여 각각 별도의 값을 유지합니다.

### `setTimeout`의 추가 인수 사용

```javascript
for (var i = 0; i < 4; i++) {
  setTimeout(
    (currentI) => {
      console.log(currentI);
    },
    10,
    i
  );
}
```

출력:

```text
0
1
2
3
```

`setTimeout`의 세 번째 이후 인수는 콜백 함수의 인수로 전달됩니다.

## 클로저 관점에서 이해하기

콜백 함수는 바깥쪽 변수 `i`에 접근하므로 클로저를 형성합니다.

```javascript
() => {
  console.log(i);
}
```

중요한 점은 클로저가 `i`의 값을 매번 복사해 저장하는 것이 아니라, `i`라는 변수를 참조한다는 것입니다.

`var`를 사용하면 모든 콜백이 같은 변수 하나를 참조합니다.

```text
콜백 1 ─┐
콜백 2 ─┤
콜백 3 ─┼──▶ 동일한 i 변수
콜백 4 ─┘
```

반면 `let`은 반복마다 별도의 변수를 생성합니다.

```text
콜백 1 ─▶ i = 0
콜백 2 ─▶ i = 1
콜백 3 ─▶ i = 2
콜백 4 ─▶ i = 3
```

---

## 핵심 정리

| 구분 | `var` | `let` |
|---|---|---|
| 스코프 | 함수 스코프 | 블록 스코프 |
| 반복별 변수 생성 | 생성하지 않음 | 새로 생성 |
| 콜백이 참조하는 값 | 모두 같은 `i` | 반복마다 다른 `i` |
| 출력 | `4, 4, 4, 4` | `0, 1, 2, 3` |

```text
최종 정답: 4, 4, 4, 4
```
