# JavaScript 일반 함수·화살표 함수와 `call()` 문제

<img width="600" height="600" alt="Image" src="https://github.com/user-attachments/assets/3603fe78-0486-4c63-ba21-6f8c01815aa4" />

## 문제

```javascript
function MyProduct(name, price) {
  this.name = name;
  this.price = price;

  this.printPrice = function () {
    console.log(this.price);
  };

  this.printPrice1 = () => {
    console.log(this.price);
  };
}

const p = new MyProduct('JS Book', 1000);

p.printPrice.call({ price: 2000 });
p.printPrice1.call({ price: 2000 });
```

### 보기

```text
A. 1000, 2000
B. 2000, 2000
C. 2000, 1000
```

---

## 정답

```text
C. 2000, 1000
```

---

## 실행 결과

```text
2000
1000
```

---

## 핵심 개념

이 문제의 핵심은 다음 두 가지입니다.

1. 일반 함수의 `this`는 호출 방식에 따라 결정된다.
2. 화살표 함수는 자신만의 `this`를 만들지 않고 바깥쪽 `this`를 사용한다.

---

## 1. `new MyProduct()` 실행

```javascript
const p = new MyProduct('JS Book', 1000);
```

`new`를 사용해 생성자 함수를 호출하면 새로운 객체가 생성됩니다.

생성자 함수 내부의 `this`는 새로 만들어진 객체를 가리킵니다.

```javascript
this === p;
```

생성자 내부에서 다음 코드가 실행됩니다.

```javascript
this.name = name;
this.price = price;
```

따라서 생성된 객체 `p`는 개념적으로 다음과 같습니다.

```javascript
const p = {
  name: 'JS Book',
  price: 1000,
  printPrice: function () {
    console.log(this.price);
  },
  printPrice1: () => {
    console.log(this.price);
  }
};
```

실제 화살표 함수의 `this` 동작은 위 객체 리터럴 표현과는 다르며, 생성자 함수가 실행될 당시의 `this`를 기억합니다.

---

## 2. 일반 함수 `printPrice`

```javascript
this.printPrice = function () {
  console.log(this.price);
};
```

`printPrice`는 일반 함수입니다.

일반 함수의 `this`는 함수가 어디에서 만들어졌는지가 아니라, 어떻게 호출되었는지에 따라 결정됩니다.

### 일반적인 메서드 호출

```javascript
p.printPrice();
```

이 경우 `this`는 `p`입니다.

```javascript
this === p;
this.price === 1000;
```

따라서 `1000`이 출력됩니다.

---

## 3. `printPrice.call({ price: 2000 })`

```javascript
p.printPrice.call({ price: 2000 });
```

`call()`은 함수를 즉시 실행하면서 첫 번째 인수로 전달한 객체를 함수 내부의 `this`로 지정합니다.

따라서 `printPrice` 내부에서는 다음과 같습니다.

```javascript
this === { price: 2000 };
```

함수 본문:

```javascript
console.log(this.price);
```

결과:

```text
2000
```

즉, 일반 함수는 `call()`을 사용해 `this`를 변경할 수 있습니다.

---

## 4. 화살표 함수 `printPrice1`

```javascript
this.printPrice1 = () => {
  console.log(this.price);
};
```

`printPrice1`은 화살표 함수입니다.

화살표 함수는 자신만의 `this`를 만들지 않습니다.

대신 함수가 생성된 바깥쪽 스코프의 `this`를 그대로 사용합니다.

이 화살표 함수는 `MyProduct` 생성자 함수가 실행되는 도중 만들어졌습니다.

그 당시 생성자 내부의 `this`는 새로 생성된 객체 `p`였습니다.

```javascript
this === p;
```

따라서 `printPrice1` 내부의 `this`는 계속 `p`를 가리킵니다.

```javascript
this.price === 1000;
```

---

## 5. `printPrice1.call({ price: 2000 })`

```javascript
p.printPrice1.call({ price: 2000 });
```

코드만 보면 `call()`로 `this`를 `{ price: 2000 }`으로 바꾸려는 것처럼 보입니다.

하지만 화살표 함수는 `call()`, `apply()`, `bind()`로 `this`를 변경할 수 없습니다.

따라서 전달한 객체는 화살표 함수의 `this`로 적용되지 않습니다.

화살표 함수 내부의 `this`는 여전히 생성자 함수 실행 당시의 `this`, 즉 `p`입니다.

```javascript
this === p;
this.price === 1000;
```

결과:

```text
1000
```

---

## 전체 실행 흐름

```text
new MyProduct('JS Book', 1000)
        ↓
새 객체 p 생성
        ↓
생성자 내부 this = p
        ↓
p.price = 1000
        ↓
일반 함수 printPrice 생성
        ↓
화살표 함수 printPrice1 생성
        ↓
printPrice1은 생성자 내부 this인 p를 기억
```

이후:

```text
p.printPrice.call({ price: 2000 })
        ↓
일반 함수이므로 call()로 this 변경
        ↓
this.price = 2000
        ↓
2000 출력
```

```text
p.printPrice1.call({ price: 2000 })
        ↓
화살표 함수이므로 call()로 this 변경 불가
        ↓
생성 당시의 this인 p 사용
        ↓
p.price = 1000
        ↓
1000 출력
```

---

## `call()`이 실행되지 않는 것은 아니다

다음 코드는 정상적으로 함수 자체를 실행합니다.

```javascript
p.printPrice1.call({ price: 2000 });
```

다만 화살표 함수에서는 `call()`의 첫 번째 인수인 `{ price: 2000 }`가 `this`로 적용되지 않을 뿐입니다.

즉:

```text
함수 실행: 됨
this 변경: 안 됨
```

---

## 일반 함수와 화살표 함수 비교

| 구분 | 일반 함수 | 화살표 함수 |
|---|---|---|
| 자신만의 `this` | 있음 | 없음 |
| `this` 결정 기준 | 호출 방식 | 생성된 바깥 스코프 |
| `call()`로 `this` 변경 | 가능 | 불가능 |
| `apply()`로 `this` 변경 | 가능 | 불가능 |
| `bind()`로 `this` 변경 | 가능 | 불가능 |

---

## 직접 비교

### 일반 함수

```javascript
const obj = {
  price: 1000,

  printPrice: function () {
    console.log(this.price);
  }
};

obj.printPrice.call({ price: 2000 });
```

출력:

```text
2000
```

### 화살표 함수

```javascript
function createProduct() {
  this.price = 1000;

  this.printPrice = () => {
    console.log(this.price);
  };
}

const product = new createProduct();

product.printPrice.call({ price: 2000 });
```

출력:

```text
1000
```

---

## 주의할 점

화살표 함수가 항상 객체 `p`를 자동으로 가리키는 것은 아닙니다.

화살표 함수는 단순히 자신이 만들어진 바깥쪽의 `this`를 사용합니다.

이 문제에서는 화살표 함수가 생성자 함수 내부에서 만들어졌고, 그 당시 생성자의 `this`가 `p`였기 때문에 `p`를 가리키는 것입니다.

---

## 핵심 정리

```javascript
p.printPrice.call({ price: 2000 });
```

- `printPrice`는 일반 함수
- `call()`로 `this` 변경 가능
- `{ price: 2000 }`이 `this`
- `2000` 출력

```javascript
p.printPrice1.call({ price: 2000 });
```

- `printPrice1`은 화살표 함수
- `call()`로 `this` 변경 불가능
- 생성자 실행 당시의 `this`, 즉 `p` 사용
- `p.price`는 `1000`
- `1000` 출력

```text
최종 정답: C. 2000, 1000
```
